# 平行人生报告生成指南 (Report Generation Guide)

当用户选择"📄 人生平行报告"时，使用此指南生成 Markdown 报告文件。

---

## 生成原则

**写作风格**：像写给未来自己的一封信——温暖、具体、平衡、克制。优先用真实细节和对话原文，而非模糊描述。带轻微文学感，但不过度修辞。

**内容选取**：
- 优先选取"平行自我展示脆弱"的对话（分享自己的遗憾）
- 用户获得新视角的时刻（"我之前没这样想过"）
- 两个自我发现共同点的时刻（"原来你也…"）
- 避免：纯信息交换、过度负面的爆发、流水账式闲聊

---

## 文件输出

- **文件名格式**：`平行人生报告_{YYYY-MM-DD}.md`
- **保存位置**：用户的当前 workspace 根目录
- **完成后**：调用 `open_result_view` 展示文件

---

## 报告结构

使用 `assets/report-template.md` 作为模板，填入以下内容：

| 模板区域 | 填入内容 |
|---------|---------|
| 分叉点 | 具体年份、A选择 vs B选择、背景描述（1-2句） |
| 你的人生 | 3-5个核心要点（工作/城市/关系/状态） |
| 平行自我的人生 | 3-5个核心要点，突出不同 |
| 对比表格 | 职业/城市/关系/心态 四个维度的对比 |
| 对话精华 | 2-3段最触动的对话，优先选脆弱/洞见/共鸣时刻 |
| 镜像遗憾 | 以平行自我的口吻叙述，第一人称，有温度 |
| 带回当下 | Phase 5 的桥接语句 + 用户在 Phase 5 的反思内容（如有） |

---

## 质量检查

生成后确认：
- [ ] 时间线有具体年份
- [ ] 对话是真实的对话内容（不是重新杜撰）
- [ ] 镜像遗憾以平行自我视角撰写，有温度
- [ ] 结尾段落平静、向前，不悲不喜
- [ ] 文件名包含今日日期
