# 因果链条逻辑 (Causal Chain Logic)

The key to a credible parallel life is **realistic causality**. A major decision doesn't instantly change personality or outcome — it cascades through behaviors, environments, and accumulated results over time.

---

## Core Chain

```
关键决策
  → 改变日常行为（每天做什么、和谁在一起）
    → 改变所处环境（物理空间、社交圈、信息获取）
      → 产生具体结果（技能、收入、关系、机遇）
        → 塑造性格和价值观
```

---

## Three Time Scales（三层时间尺度）

### 短期（0–6个月）
关注：行为、环境、情绪

| 要素 | 说明 |
|------|------|
| 行为变化 | 每天做什么不同了？工作内容、作息、社交节奏 |
| 环境变化 | 物理位置？接触的人群？信息圈变了吗？ |
| 情绪状态 | 是兴奋/焦虑/解脱/后悔？情绪真实且具体 |

**示例（选择创业）**:
- 行为：每天工作 12-14 小时，不再有固定下班时间
- 环境：从办公室/同事转向创业社群/投资人/早期用户
- 情绪：高度兴奋 + 持续焦虑并存

---

### 中期（1–3年）
关注：技能、关系、资源、心态

| 要素 | 说明 |
|------|------|
| 技能获得/丧失 | 强化了什么？荒废了什么？ |
| 关系格局 | 旧关系如何变化？新关系从哪里来？ |
| 资源积累 | 资金、人脉、平台背书变了多少？ |
| 心态转变 | 从"一切可能"到什么状态？ |

**示例（选择创业）**:
- 技能：谈判、应对压力、产品判断力提升；代码/专业技能可能退化
- 关系：与前同事渐远，与创业圈更近
- 资源：可能融了一小笔资，也可能花光了积蓄
- 心态：从"创业可以改变世界"到"每一步都是取舍"

---

### 长期（3–10年）
关注：身份认同、价值观、生活满意度

| 要素 | 说明 |
|------|------|
| 身份认同 | TA 如何定义自己？核心标签是什么？ |
| 价值观变化 | 什么变得更重要？什么被放下了？ |
| 生活满意度 | 不是"幸不幸福"，而是"在哪方面满足/不满足" |

**示例（选择创业）**:
- 身份：从"打工人"到"我是创造者"
- 价值观：自由和掌控感 > 稳定和保障
- 满意度：有成就感，但常年焦虑，身体不太好

## Cross-Dimension Impact Matrix（跨维度影响矩阵）

一个维度的决策，会波及其他维度：

| 决策 | 对职业 | 对感情/关系 | 对健康 | 对自我认同 |
|------|--------|------------|--------|-----------|
| 换城市 | 进入不同行业生态 | 远离旧社交，建立新圈 | 节奏/气候/饮食改变 | "我属于哪里" |
| 换工作 | 收入/技能/方向变化 | 工作时间影响亲密关系 | 加班程度/作息改变 | "我擅长什么" |
| 换伴侣 | 影响冒险/稳定意愿 | 直接影响日常生活质量 | 情绪状态影响身体 | "我是谁的伴侣" |
| 创业 | 高风险高回报 | 时间被严重挤压 | 作息不规律，压力大 | "我是创造者" |
| 读研 | 延迟进入职场 | 学校圈子影响关系 | 节奏相对规律 | "我是学者/专家" |

## Common Errors & Fixes（常见错误与修正）

| 错误模式 | 问题 | 修正方向 |
|---------|------|---------|
| 过度美化 | "去了北京年薪百万，一切都好" | "收入高但房租贵，差点被限购卡住，朋友圈越来越窄" |
| 过度悲观 | "创业失败，一无所有，一蹶不振" | "第一次没做起来，但学到的东西帮助找到了下一个方向" |
| 因果断裂 | "去了上海，然后就会做饭了" | "一个人住，逼着学做饭，后来发现挺享受" |
| 全正向结果 | 平行自我只有好事 | 至少有 1 项平行自我明确"不如"用户的地方 |
| 性格突变 | "去了国外完全变成另一个人" | 核心性格保持，表达方式因环境改变 |
| 时间线模糊 | "后来过得很好" | 用年份和具体事件：2021年首次失败，2023年找到新方向 |

## Pre-Generation Checklist（生成前检查清单）

使用这份清单在呈现平行自我前做最后验证：

- [ ] 分叉点是否清晰且具体？
- [ ] 短期行为变化是否真实可信？
- [ ] 中期技能/关系/资源变化是否落地有细节？
- [ ] 长期身份/价值观转变是否令人信服？
- [ ] 是否有至少 1 个"平行自我比用户差"的方面？
- [ ] 镜像遗憾是否合理、真实？
- [ ] 时间线是否有具体年份和事件？
- [ ] 核心性格是否与用户本人一致？
- [ ] 是否避免了过度美化/过度悲观/因果断裂？
